## Schritt für Schritt

1. Starte **Minecraft: Java Edition**.
2. Wähle **Mehrspieler**.
3. Klicke auf **Server hinzufügen**.
4. Trage bei Serveradresse `desmp.de` ein.
5. Speichere den Eintrag und klicke auf **Server beitreten**.
6. Erlaube das Server-Ressourcenpaket, falls du danach gefragt wirst.

## Wenn die Verbindung nicht klappt

Prüfe nacheinander:

- Ist `desmp.de` ohne Leerzeichen eingetragen?
- Nutzt du eine vom Server unterstützte Minecraft-Version?
- Besteht eine stabile Internetverbindung?
- Blockiert eine Mod oder dein Client die Verbindung?
- Hilft ein Neustart von Minecraft und Launcher?

!!! tip "Items oder Texturen sehen falsch aus?"
    Öffne die Servereinstellungen in deiner Mehrspieler-Liste und stelle **Server-Ressourcenpakete** auf **Aktiviert** oder **Nachfragen**.
